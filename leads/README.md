# Сбор клиентов (лиды с телефонами для WhatsApp)

Скрипт `collect_leads.py` берёт бизнесы из каталога 2ГИС по городу и нише и сохраняет телефоны.

```bash
export DGIS_KEY=...          # бесплатный ключ: https://dev.2gis.com/
python3 leads/collect_leads.py --city Алматы --pages 6 \
  --query автосервис --query "салон красоты" --query стоматология
```

Результат в `leads/out/`:

- `<город>.csv` — название, рубрики, адрес, все телефоны, email, сайт, соцсети, рейтинг, число отзывов.
  Колонка `whatsapp_candidate` — номер для рассылки, `whatsapp_confirmed=yes` значит у бизнеса в 2ГИС указана ссылка wa.me.
- `<город>_whatsapp.txt` — только номера, по одному в строке, в формате `+7XXXXXXXXXX`. Подтверждённые WhatsApp идут первыми.

Флаг `--no-website-only` оставляет только бизнесы без сайта (тёплая аудитория для продажи сайта или бота).
